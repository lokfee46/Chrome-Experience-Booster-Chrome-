Ubiquitous Web Optimizer v2：一个为流畅、纯净浏览而生的用户脚本
为什么我要做这个？
每天上网，我们总会遇到同样的烦恼：

到处是分散注意力的广告，页面加载慢、布局乱。

晚上想继续阅读，刺眼的白色背景让眼睛难受。

页面太长，想回顶部得疯狂滑动鼠标。

后台标签页里无用的动画和计时器还在偷偷消耗 CPU，笔记本风扇呼呼转。

我受够了这些“互联网噪音”。于是决定写一个 用户脚本，一次性解决多个痛点。这就是 Ubiquitous Web Optimizer v2 —— 一个轻量、无侵入、可自由关闭的网页优化助手。

三大核心特点
1. 智能广告过滤 —— 还你干净页面
基于 关键词 + CSS 选择器 + 角色属性 多重匹配，精准识别常见广告框。

不依赖外部规则文件，启动即用，实时监视 DOM 变化，新加载的广告也会自动隐藏。

被隐藏的元素不会残留占位，版面立即清爽。

2. 悬浮控制面板 —— 可拖拽、可记忆、一键夜间模式
页面右侧一个毛玻璃面板，包含“夜间模式”和“返回顶部”按钮。

随意拖拽 面板位置，松开后自动保存，下次打开依然在你喜欢的位置。

夜间模式 采用全局滤色 + 二次反色技术，保护眼睛同时避免图片颜色怪异（图片、视频会智能修正）。

双击页面空白区域 也能平滑回顶，无需寻找按钮。

3. 后台定时器智能冻结 —— 省电、降温、释放资源
拦截页面的 setTimeout / setInterval，当标签页不可见时自动暂停所有定时器。

切换回标签页后恢复执行，且保留剩余延迟时间。

从此多开标签页时，后台页面不再偷偷运行无意义轮询，CPU 占用明显下降。

✨ 额外贴心功能：快捷网站管理
你可以在面板上自由添加常用网站链接（如新闻、工作台、社交首页），一键跳转。

支持删除、持久化存储，最多保存 12 个。

如何安装？
安装脚本管理器
该脚本需要运行在浏览器扩展环境中。推荐使用：

Violentmonkey (开源、轻量、兼容性好)

Tampermonkey (功能强大)

在 Edge / Chrome / Firefox / Thorium 等浏览器的扩展商店搜索安装即可。

添加新脚本
打开管理器面板，点击「添加新脚本」或「新建用户脚本」，删除编辑器里自动生成的代码，然后将下面的完整脚本代码粘贴进去。

保存并启用
按 Ctrl+S 或点击保存。脚本默认匹配所有网址（*://*/*），无需额外设置。

体验
任意网站右侧会出现半透明悬浮面板。你可以拖拽移动、点击夜间模式、添加快捷网站。双击页面空白区域（避开按钮/链接）即可平滑回顶。
