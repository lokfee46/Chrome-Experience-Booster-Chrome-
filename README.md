## 🚀 Chrome-Experience-Booster (Chrome 体验重构加速器)

一款基于 **DeepSeek-V4 (AI)** 深度定制的开源油猴（Tampermonkey）脚本。旨在通过硬核的底层代码，彻底解决谷歌浏览器（Chrome）吃内存、强推 Manifest V3 阉割广告拦截、以及交互呆板等核心痛点。

Chrome 虽好，但它现在越来越像一个“步入中年的优等生”——臃肿、吃内存、而且为了自家的广告利益开始限制传统的去广告插件。
既然官方不作为，那我们就用 **AI + 篡改猴（Tampermonkey）** 亲自动手，物理“篡改”那些反人类的网页体验！

本项目所有核心逻辑均由 **DeepSeek-V4-Pro (Thinking 模式)** 进行高强度推演与编写，确保在最轻量化的代码下实现最强性能。

## 🔥 核心痛点与功能实现

### 1. 🧠 内存与后台降噪 (反击 Chrome 吃内存)
* **痛点：** 网页后台疯狂吃 CPU 和内存，笔记本掉电极快。
* **AI 优化：** 脚本动态监听 `visibilityState`。当标签页切入后台时，自动降低 DOM 渲染频率并限制非必要定时器，让你的 Chrome 瞬间降温。

### 2. 🛡️ 元素级垃圾强滤 (反击 Manifest V3 限制)
* **痛点：** 谷歌强推 MV3 导致传统去广告插件被“紧箍咒”限制。
* **AI 优化：** 采用高效的 `MutationObserver` 异步监听，在网页垃圾元素（如伪装成下载按钮的广告、弹窗）渲染出来的瞬间将其从 DOM 树中**物理抹除**，不占内存。

### 3. 🛠️ 极客悬浮窗与手势 (补齐 Chrome 原生功能短板)
* **痛点：** 网页自带交互死板，长截图、夜间模式全靠装一堆臃肿的第三方插件。
* **AI 优化：** 
  * 为所有网页注入一个优雅、半透明的**悬浮工具栏**。
  * 集成**一键全网页暗黑模式**（通过高效率 CSS 滤镜实现，不卡顿）。
  * 支持**双击空白处一键置顶**，省去鼠标滚轮的痛苦。

## 🚀 如何安装使用？

1. **前提条件：** 确保你的 Chrome 浏览器已经安装了 [篡改猴 (Tampermonkey)](https://www.tampermonkey.net/) 插件。
2. **一键安装：** 点击本项目中的 `chrome-booster.user.js` 文件，点击 **Raw** 按钮，篡改猴会自动弹出安装界面，点击“安装”即可。
3. **开源共建：** 本项目代码完全开源，欢迎在 Issue 中提出新的网页优化需求，我会继续调教 DeepSeek V4 迭代更新！
